# Programming Fundamentals Exercises

This repository contains solutions for all 10 exercises from the Programming Fundamentals module. Each exercise has its own folder with Python code and a README file.

---

## Exercises

### 01-CodingIsCool

* **File:** `coding_is_cool.py`
* Prints "Coding is Cool" using variables and string concatenation.

### 02-SimpleSums

* **File:** `simple_sums.py`
* Performs addition of two numbers and prints the result.

### 03-Biography

* **Files:** `biography.py` (basic), `biography_advanced.py` (advanced)
* Stores and prints user information (name, hometown, age) using a dictionary.
* Advanced version handles multi-word names and user input.

### 04-PrimitiveQuiz

* **Files:** `primitive_quiz.py` (basic), `primitive_quiz_advanced.py` (advanced)
* Asks the user a question and checks the answer.
* Advanced version ignores capitalization and is prepared for multiple questions.

### 05-DaysOfTheMonth

* **Files:** `days_of_the_month.py` (basic), `days_of_the_month_advanced.py` (advanced)
* Prints the number of days in a month.
* Advanced version accounts for leap years in February.

### 06-BruteForceAttack

* **Files:** `brute_force.py` (basic), `brute_force_limited.py` (optional)
* Simulates password entry until correct.
* Optional version limits attempts and shows remaining attempts.

### 07-SomeCounting

* **File:** `some_counting.py`
* Demonstrates counting with for loops over various ranges and increments.

### 08-SimpleSearch

* **Files:** `simple_search.py` (basic), `simple_search_optional.py` (optional)
* Searches for a specific string in a list.
* Optional version allows user input for the search term.

### 09-Hello

* **File:** `hello.py`
* Defines a function that prints "Hello" and calls it from main().

### 10-IsItEven

* **File:** `is_it_even.py`
* Checks whether a user-entered number is even or odd.
